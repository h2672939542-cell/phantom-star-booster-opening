# Phantom Star — 30th Anniversary Booster Opening

宝可梦卡包开包互动页面，包含撕包、翻牌、稀有度特效和自定义配置。

## 使用

下载仓库并用支持 WebGL 的现代浏览器打开 `index.html`。页面需要联网加载 Three.js 和字体。

## 默认图片

- 默认卡面：皮卡丘 ex、梦幻 ex、三合一磁怪、耿鬼 ex、喷火龙 ex、水箭龟 ex。
- 统一卡背：宝可梦卡背。
- 所有默认图片均已内嵌在 HTML 中，无需单独下载图片文件。

点击 Customize 可以更换卡面、卡背和包装图片，调整抽卡数量与概率。自定义配置保存在当前浏览器中；恢复默认会还原本仓库内置的卡面和卡背。

默认每包 6 张，按稀有度概率随机抽取，可能出现重复卡面。
